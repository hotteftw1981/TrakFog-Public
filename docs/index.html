⭐ Highlights

Deine Tesla-Daten, sinnvoll zusammengesetzt.

TrakFog verbindet aktuelle Fahrzeugdaten mit einer langfristig nutzbaren Historie und einer Oberfläche, die vom Desktop bis zum Tesla-Browser funktioniert.

📡

Live-Daten

Fahrzeugzustand, Position, Akku, Geschwindigkeit, Leistung, Temperaturen und mehr.

Ladekurven, Energie, Standorte und Tesla-Supercharger-Kostensync, wenn verfügbar.

📺 LiveView-Zugang

Ein Link. Eine PIN. Kein Backend-Login.

LiveView ist für Tesla-Browser, Tablet, TV und Wanddisplay gedacht und bewusst vom normalen TrakFog-Benutzerlogin getrennt.

So einfach geht es

  1. Im gewünschten Browser /live.php deiner TrakFog-Domain öffnen.
  2. Im PIN-Modus die konfigurierte sechsstellige LiveView-PIN eingeben.
  3. Optional Gerät merken aktivieren.
  4. Danach öffnet dieses vertrauenswürdige Gerät LiveView innerhalb der konfigurierten Dauer ohne erneute PIN.

Normale TrakFog-Zugangsdaten werden für LiveView nicht benötigt. Vertrauenswürdige Geräte können im Backend jederzeit einzeln oder gesammelt widerrufen werden.

Direktzugang
https://deine-domain/live.php

Modi
PIN → 6-stellige LiveView-PIN
Offen → direkter Zugriff
Deaktiviert → kein Zugriff

Tesla-Schlaf
LiveView liest gespeicherte Daten.
Ein offenes Display weckt das Fahrzeug nicht zusätzlich auf.

🚀 Schnellstart

In drei Schritten zum eigenen TrakFog.

Du brauchst einen Docker-Host, Docker Compose und sichere lokale Datenbank-Passwörter. Portainer funktioniert ebenfalls und ist optional.

01

Repository & Konfiguration

stable klonen, .env.example nach .env kopieren und die Datenbank-Passwörter ändern.

02

Stack starten

Den Stack mit Docker Compose bauen und im Browser öffnen. Die Daten bleiben auf deinem Host.

03

Owner sicher anlegen

Den Installationsschlüssel lokal im Webcontainer lesen, im Wizard eingeben und danach optional Tesla verbinden.

Docker Compose · Schnellstart

Terminal · Docker Host
git clone https://github.com/hotteftw1981/TrakFog-Public.git
cd TrakFog-Public
git switch stable
cp .env.example .env
# .env öffnen und sichere Passwörter eintragen!
docker compose up -d --build
# Nur lokal ausführen und geheim halten:
docker exec trakfog-web cat /var/lib/trakfog/setup_token

Anschließend http://SERVER-IP:8780 öffnen und den 64-stelligen Installationsschlüssel beim ersten Owner-Konto eingeben. Den Schlüssel niemals in GitHub-Issues oder Screenshots teilen.

💬 Community & Sicherheit

Feedback erwünscht. Private Daten bleiben privat.

TrakFog V0.1.1.90 ist eine Public Beta. Fehlerberichte helfen bei der Weiterentwicklung – bitte niemals Tesla-Tokens, VINs, präzise Standorte oder persönliche Logdaten veröffentlichen.

🐞Fehler melden ↗Bug-Template mit Version, Schritten und anonymisierten Informationen. 🛡️Sicherheitslücke melden ↗Vertrauliche Meldungen über die GitHub-Sicherheitsfunktion, niemals als öffentliches Issue. 🚘Warum abstrakte Autos? ↗Sechs eigens erstellte, generische SVG-Grafiken statt nicht freigegebener Tesla-Renderings.

Deine Daten gehören auf deinen Server. TrakFog benötigt kein eigenes Cloud-Konto. Für die Tesla-Anbindung brauchst du gültige Tesla-Zugangstokens; aktivierte Karten- und Geocoding-Dienste können ebenfalls Daten an externe Anbieter übermitteln.
