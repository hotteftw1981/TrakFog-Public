⭐ Highlights

Deine Tesla-Daten, sinnvoll zusammengesetzt.

TrakFog verbindet aktuelle Fahrzeugdaten mit einer langfristig nutzbaren Historie und einer Oberfläche, die vom Desktop bis zum Tesla-Browser funktioniert.

📡

Live-Daten

Fahrzeugzustand, Position, Akku, Geschwindigkeit, Leistung, Temperaturen und mehr.

🛣️

Fahrten & Historie

Automatische Fahrterkennung, Routen, Verbrauch, Zeiten und Detailansichten.

⚡

Laden & Kosten

Ladekurven, Energie, Standorte und Tesla-Supercharger-Kostensync, wenn verfügbar.

🗺️

Live Map & Reisen

Zentrierter Tesla mit Fahrfaden, Geofences, Reise-Timeline und Gesamtkarte.

🧠

NerdView

Technische Fahrzeug-, Lade-, Klima- und Positionsdaten in einer eigenen Ansicht.

⬆️

Stable Self-Updates

GitHub Releases, eigener Docker-Updater, Migrationen und Versionsbestätigung aus einem Update-Center – ohne Portainer-Zwang.

↔

Datenmigration

TeslaMate-Backups direkt übernehmen und TrakFog-Daten als portables ZIP exportieren oder wieder importieren.

🔗

Integration API

SoC, Ziel-SoC, Ladezustand und Fahrzeugstatus sicher an Systeme wie VoltCore bereitstellen – ohne Tesla-Tokens weiterzugeben.

🧭

Ersteinrichtung

Frische Docker-Instanzen führen sicher durch Systemcheck, ersten Owner, optionale Tesla-Verbindung und Datenübernahme.

🌌

Living Dashboard

Mehrere Teslas nebeneinander auswählen und den aktuellen Fahrzeugzustand in einer lebendigen, statusabhängigen Hero-Bühne erleben.

↔ Datenmigration

Historie mitnehmen statt neu anfangen.

TrakFog besitzt ein eigenes Import-/Export-Center für den Wechsel aus anderen Tesla-Loggern und für portable TrakFog-Umzüge.

Heute bereits aktiv

  1. TeslaMate-PostgreSQL-Backup / .bck hochladen.
  2. TrakFog erkennt Fahrzeuge, Fahrten, Positionshistorie, Laden, Orte und Zustände.
  3. VIN-basierte Zuordnung und Dubletten-Schutz prüfen vorhandene Historie.
  4. Große Importe laufen im Hintergrund mit Fortschrittsanzeige weiter.
  5. TrakFog selbst kann als portables ZIP exportiert und auf einer anderen Installation wieder importiert werden.

📺 LiveView-Zugang

Ein Link. Eine PIN. Kein Backend-Login.

LiveView ist für Tesla-Browser, Tablet, TV und Wanddisplay gedacht und bewusst vom normalen TrakFog-Benutzerlogin getrennt.

So einfach geht es

  1. Im gewünschten Browser /live.php deiner TrakFog-Domain öffnen.
  2. Im PIN-Modus die konfigurierte sechsstellige LiveView-PIN eingeben.
  3. Optional Gerät merken aktivieren.
  4. Danach öffnet dieses vertrauenswürdige Gerät LiveView innerhalb der konfigurierten Dauer ohne erneute PIN.

Normale TrakFog-Zugangsdaten werden für LiveView nicht benötigt. Vertrauenswürdige Geräte können im Backend jederzeit einzeln oder gesammelt widerrufen werden.

Direktzugang
https://deine-domain/live.php

Modi
PIN → 6-stellige LiveView-PIN
Offen → direkter Zugriff
Deaktiviert → kein Zugriff

Tesla-Schlaf
LiveView liest gespeicherte Daten.
Ein offenes Display weckt das Fahrzeug nicht zusätzlich auf.
🌿 Release-Modell

Zwei Branches. Zwei klare Aufgaben.

stable

Community

Veröffentlichte, geprüfte Releases. Dieser Branch ist für Installation und integrierte Updates vorgesehen.

main

Entwicklung

Aktueller Entwicklungsstand für Tests und neue Funktionen. Nicht die allgemeine Installationsquelle.

🚀 Installation

Docker Compose first.

Die Installation folgt dem veröffentlichten stable-Branch. Portainer bleibt eine optionale Oberfläche.

Docker Compose Kurzstart

  1. Repository hotteftw1981/TrakFog-Public klonen.
  2. Auf den Branch stable wechseln.
  3. .env.example nach .env kopieren und sichere DB-Werte setzen.
  4. docker compose up -d --build ausführen.
  5. Im Webcontainer den einmaligen Setup-Schlüssel lokal abfragen und damit Owner/Tesla/Datenübernahme im Wizard einrichten.
  6. Reverse Proxy/HTTPS final prüfen.
